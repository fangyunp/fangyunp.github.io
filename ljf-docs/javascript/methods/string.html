字符串方法 ​

来源：js/基础/3方法.html

速查导航 ​

字符相关

  • charAt — 返回指定位置字符
  • charCodeAt — 返回 Unicode 编码
  • codePointAt — 返回码点（支持代理对）

判断相关

  • startsWith — 是否以指定内容开头
  • endsWith — 是否以指定内容结尾
  • includes — 是否包含

截取相关

  • split — 分割为数组
  • substr — 截取（起始+长度）
  • substring — 截取（起始+结束）
  • slice — 切片（支持负数）

大小写

  • toLowerCase — 转小写
  • toUpperCase — 转大写

替换相关

  • replace — 替换（首个/正则）
  • replaceAll — 全部替换

正则匹配

  • match — 匹配结果
  • matchAll — 全部匹配（含位置）
  • search — 搜索返回索引

空白处理

  • trim — 去除首尾空白

补全相关

  • padStart — 头部补全
  • padEnd — 尾部补全

重复

  • repeat — 重复拼接

查找相关（数组也有）

  • indexOf — 正向查找索引
  • lastIndexOf — 反向查找索引

拼接

  • concat — 拼接字符串

索引访问

  • at — 索引访问（支持负数）

数值解析

  • parseInt / parseFloat — 解析数值

字符相关 ​

String.fromCharCode() — 识别大于 0xFFFF 的字符（UCS-2） String.fromCodePoint() — 正确处理 4 字节存储的字符（UTF-16）

charAt ​

charAt() 返回指定位置的字符。

js

charCodeAt ​

charCodeAt() 返回指定索引位置字符的 Unicode 值。

js

codePointAt ​

codePointAt() 正确处理 4 个字节储存的字符，返回一个字符的码点。

js

判断相关 ​

startsWith ​

startsWith() 检测字符串是否以指定子字符串开始，第二个参数从指定下标位置开始搜索。

js

endsWith ​

endsWith() 判断当前字符串是否以指定子字符串结尾，第二个参数针对前 n 个字符。

js

includes ​

includes() 是否包含指定子字符串，第二个参数从指定下标位置开始搜索到结束。

js

split ​

js

substr ​

substr() 截取字符串，从下标开始截取多少个。

js

substring ​

substring() 截取字符串，两个下标之间。

js

slice ​

slice() 截取（支持负数索引）。

js

toUpperCase ​
