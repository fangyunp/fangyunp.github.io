速查导航 ​

  • Array.from — 字符串 — 字符串转数组
  • Array.from — Set — Set 去重转数组

  • splice — 删除/插入元素
  • sort — 排序
  • pop — 末尾删除
  • shift — 开头删除
  • push — 末尾添加

  • copyWithin — 内部复制替换

遍历方法

  • forEach — 遍历（无返回值）
  • every — 全部满足
  • some — 任一满足

  • map — 映射
  • reduce — 归约（从左到右）
  • reduceRight — 归约（从右到左）

  • findIndex — 查找索引
  • flat — 扁平化
  • at — 索引访问（支持负数）
  • keys / values / entries — 迭代器

迭代相关知识 ​

目前有 [Symbol.iterator] 方法的类型有：

  • 字符串 String
  • 数组 Array
  • 映射 Map
  • 集合 Set
  • arguments 对象
  • NodeList 等 DOM 集合

for...of 无法遍历对象，因为对象不具有 Iterator。 类数组对象可以通过 obj[Symbol.iterator] = Array.prototype[Symbol.iterator] 去迭代。

for...in 不推荐遍历数组：数字会被转化为字符串，没有 break。

  • 自身会遍历原型链上的属性（公有 prototype 的属性）
  • for...in 无法遍历 Symbol 属性（不可枚举）
